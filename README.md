# Мини-Склад

Учебная конфигурация на платформе **1С:Предприятие 8.3**, созданная по материалам
пособия М.Г. Радченко «1С:Предприятие 8.3. Практическое пособие разработчика».

Реализует минимальный контур складского учёта.

## Что внутри

**Подсистема:** `Мини-Склад`

**Справочники:**
- `Товары` — номенклатура
- `Контрагенты` — поставщики и покупатели

**Документы:**
- `Поступление` — приход товаров на склад (движение «Приход»)
- `Реализация` — списание товаров со склада (движение «Расход»)

## Как открыть

1. Создайте новую пустую информационную базу в Конфигураторе.
2. Выполните **Конфигурация → Загрузить конфигурацию из файлов…**
3. Укажите папку `src/` (там, где находится `Configuration.xml`).
4. Выполните **Конфигурация → Обновить конфигурацию базы данных (F7)**.
5. Запустите **1С:Предприятие (F5)**.
