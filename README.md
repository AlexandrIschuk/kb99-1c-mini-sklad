# Мини-Склад

Учебная конфигурация на платформе **1С:Предприятие 8.3**, созданная по материалам
пособия М.Г. Радченко «1С:Предприятие 8.3. Практическое пособие разработчика».

Реализует минимальный контур складского учёта.

## Что внутри

**Подсистема:** `Мини-Склад`

**Справочники:**
- `Товары` — номенклатура
- `Контрагенты` — поставщики и покупатели

**Документы:**
- `Поступление` — движение «Приход»
- `Реализация` — движение «Расход»

## Как открыть

1. Скачайте архив репозитория с GitHub и распакуйте архив.
2. Создайте новую пустую информационную базу в Конфигураторе.
3. Выполните **Конфигурация → Загрузить конфигурацию из файлов…**, Загрузить из - выберите `XML-файлы`
5. Укажите распакованную папку `kb99-1c-mini-sklad-master` (там, где находится `Configuration.xml`).
6. Выполните **Конфигурация → Обновить конфигурацию базы данных (F7)**.
7. Запустите **1С:Предприятие (F5)**.
